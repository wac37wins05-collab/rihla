## 🏆 Tier S — Leaders mondiaux (couverture complète DMC/TO)
 
### 1. **Tourplan** 🇳🇿
- **HQ** : Auckland (Nouvelle-Zélande)
- **Cible** : grands inbound tour operators, DMCs > 50 staff, séries groupe
- **Forces** : ERP "database first", contracting allotments massif, comptabilité native, séries (best-of-Italy hebdo), API ↔ XML in/out
- **Faiblesses** : UX legacy, on-premise lourd, lent à implémenter (12-18 mois)
- **Clients** : Kuoni, Globus, AAT Kings, Tucan Travel, Goway
 
### 2. **Lemax** 🇭🇷
- **HQ** : Zagreb (Croatie)
- **Cible** : mid-to-large tour operators et DMCs (CRM unifié, pricing à $10K+/an)
- **Forces** : Inventaire central, package builder visuel, B2B portal, workflow automation, CRM unifié, distribution XML out
- **Clients** : Asian Trails (DMC Thaïlande), Etihad Holidays, Travelive
 
### 3. **Tourwriter** 🇳🇿
- **HQ** : Auckland (NZ)
- **Cible** : agences luxe / DMCs sur mesure < 50 staff
- **Forces** : "Experience first" — itineraries design-first, intégration Xero, speed-to-quote rapide
- **Comparaison** : alternative moderne/cloud à Tourplan
- **Clients** : Audley, Black Tomato, Backyard Travel
 
### 4. **Travel Studio** (Open Destinations) 🇮🇳/🇬🇧
- **HQ** : Londres + Bangalore
- **Cible** : grands DMCs et tour operators luxury
- **Forces** : modules Itinerary Designer + Reservations + Accounts + B2B portal, multi-pays, multi-devises
- **Clients** : abercrombie & kent, Andbeyond, Cox & Kings DMC
 
### 5. **Travel Booster** (Galor) 🇮🇱
- **HQ** : Tel Aviv (Israël)
- **Cible** : ERP complet inbound + outbound + corporate
- **Forces** : Gestion hôtels + activités + transferts + croisières, omni-canal (B2B/B2C/B2B2C/E), API TBAPI pour clients revendeurs
- **Clients** : Issta, Eshet Tours, Avia Group

## 🥇 Tier 1 — Spécialistes DMC modernes / cloud-native
 
### 6. **Ezus** 🇫🇷
- **HQ** : Paris
- **Cible** : DMCs 500+ trips/an, agences B2B sur-mesure
- **Forces** : drag-drop itinerary builder, supplier API, PDF proposals avancées, gestion fournisseurs
- **Pricing** : ~$199/mois/user
 
### 7. **Wetu** 🇿🇦
- **HQ** : Le Cap (Afrique du Sud)
- **Cible** : agences boutique, DMCs Afrique/Inde
- **Forces** : itinéraires visuels interactifs (web/app traveler), library destinations massive (Afrique +++), feedback voyageur
- **Pricing** : $75/mois/user (Lite), $250/mois (full)
- **Clients** : ~10K+ agences travel professionnels
 
### 8. **Odys (Odys.travel)** 🇫🇷
- **HQ** : Paris
- **Cible** : agences mid/large hybrides inbound+outbound
- **Forces** : propositions media-rich live-edit, IA-driven pricing, collaboration temps réel client/agent
- **Pricing** : ~$300/mois
 
### 9. **TravelTree** 🇬🇪/🌐
- **HQ** : Tbilissi
- **Cible** : DMCs et travel agents tailor-made
- **Forces** : itinéraires + propositions + ops + IA, customisation au cas par cas sans surcoût
 
### 10. **mTrip** 🇨🇦
- **HQ** : Montréal
- **Cible** : DMCs ground operators (white-label)
- **Forces** : programmes traveler-app brandable client, AI Import Wizard, Tour Leader tools, hors ligne
- **Couverture** : 35+ pays, 4M voyages/an
 
### 11. **Adivaha DMC Suite** 🇮🇳
- **HQ** : Inde (IATA accredited)
- **Cible** : inbound TO Inde / Asie / MENA

### 12. **Goodwin (Travel Business OS)** 🌐
- **HQ** : Estonie
- **Cible** : OTAs, tour operators, DMCs hybrides

### 13. **TourX** (Hyperguest stack) 🇨🇾

- **Cible** : tour operators + agences moyennes
- **Forces** : modulaire (Aurora flights, Zenith mid-office), 30j time-to-first-booking, flat pricing
- **Trusted by** : 150+ TOs/agencies
 
### 14. **Travelize** (Lemax-like CIS) 🇷🇺

### 15. **Travelify (par Travel Booster)** 🇮🇱

### ✅ Forces RIHLA vs concurrents
- **All-in-one** : couvre Tourplan (ERP) + Tourwriter (design) + Wetu (B2B portal) + Bókun (activities) + Travel Booster (omnicanal) + un agent designer IA
- **Marque-aware** : palette bordeaux/ivoire native S'TOURS, pas un theme générique
- **CRM-first DMC** : RFM + 360° + pipeline 10 étapes spécifique tourisme (vs CRM générique HubSpot/Salesforce)
- **Mode démo zéro setup** : tous les modules livrent des données seed-démo testables sans credentials externes
- **Multi-tenant** : `company_id` partout (vs Tourplan/Tourwriter mono-instance)
- **Stack moderne** : FastAPI + React + Tailwind + Vite (vs legacy Tourplan VB6, Travel Booster .NET monolithe)
 
### 🎯 Gaps à combler pour rivaliser top tier
1. **Connectivité GDS / wholesalers** — intégrer Hotelbeds + TBO Holidays + Webbeds APIs (live availability/pricing)
2. **Channel manager** — sortir l'inventaire propriétaire vers Bókun, Viator, GYG, Klook
3. **Compta complète multi-devises + multi-pays** — au-delà OHADA, ajouter US GAAP / IFRS
4. **Mobile native** — passer les 4 apps mobiles HTML actuelles en React Native ou Flutter (App Store + Play Store réels)
5. **Marketplace traveler-facing B2C** — branchement portail consommateur + paiement + DSP
6. **Tour leader live tracking GPS** — geolocation temps réel pendant voyage (côté guide + chauffeur)
7. **Connectivity Galileo/Amadeus/Sabre** — pour billets d'avion classiques
8. **NDC airline** — direct connect compagnies (Royal Air Maroc, Air France, Emirates)

## 💡 Recommandations stratégiques pour S'TOURS / RIHLA
 
### Court terme (3-6 mois) — Catch-up parité
- CRM-2/3/4 terminés (Lead Inbox, Pipeline DMC, Reporting)
- Brancher 1 wholesaler live (Hotelbeds ou TBO)
- App mobile React Native MVP (Travel Designer + Client)
 
### Moyen terme (6-12 mois) — Différentiation
- Joule Agents IA opérationnels (réservation auto + risque fournisseur + dynamic pricing)
- Connectivity 2-3 GDS / NDC airlines
- White-label SaaS pour autres DMCs MENA (vendre RIHLA à 5-10 DMCs au Maghreb)
 
### Long terme (12-24 mois) — Position de leader régional
- RIHLA = "Tourplan / Lemax pour MENA + Afrique francophone"
- Multi-tenant SaaS commercialisé
- Connectivité 10+ wholesalers + 5+ NDC + 3+ GDS
- Marketplace B2B regional (DMCs ↔ agences européennes)
